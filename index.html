01 / ABOUT

Not an operating system.
An operating environment.

CodeOS는 로컬 개발 환경을 하나의 경험으로 묶습니다. 필요한 도구와 서비스는 가까이, 복잡한 설정은 뒤로.

02 / TERMINAL

Built for the terminal.

터미널에서 상태를 확인하고 환경을 제어합니다. 빠르고 단순하게, 개발에 집중할 수 있도록.

$ codeos status

03 / FEATURES

Simple by design.

01

Local

환경은 내 컴퓨터에서 실행됩니다. 불필요한 클라우드 계층 없이.

02

Developer First

터미널과 도구를 중심으로 실제 개발 흐름에 맞춰 설계합니다.

03

Extensible

필요한 기능을 추가하고 자신만의 개발 환경으로 확장할 수 있습니다.
