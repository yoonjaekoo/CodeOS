# AGENTS.md

## 테스트 / 검증은 지시받았을 때만

**사용자가 명시적으로 지시하지 않으면 테스트하지 않는다.**

- "테스트해줘", "검증해줘", "확인해줘" 같은 지시가 있기 전까지 스스로 검증 절차를 시작하지 않는다.
- 하지 말 것: 브라우저 조작·화면 확인, 스크린샷/실측값 읽기, 시나리오 실행, 임시 스크립트나
  fixture 작성, API를 두드려 동작 확인, 로그 확인, 서버 띄워서 재현해 보기, 통과할 때까지 반복 실행.
- 코드 작성·수정까지만 한다. 동작 확인은 사용자가 시킬 때 한다.
- 지시받아 테스트할 때도 그 범위 안에서만 하고, 임의로 범위를 넓히지 않는다.
- 예외: 사용자가 시킨 작업 자체에 필요한 실행(예: git push)은 테스트가 아니므로 그대로 한다.
